# Commu-nect 🏢

[cite_start]An efficient website-based application for faster barangay response[cite: 44, 45]. [cite_start]Designed for Gen T. De Leon to centralize reporting, improve transparency, and reduce face-to-face queue congestion[cite: 67].

## ✨ Core Features
* [cite_start]**Report Page**: Users can take pictures, indicate what happened, and upload[cite: 17, 18, 19, 20]. [cite_start]Admins are notified and assign personnel[cite: 21, 22, 23].
* [cite_start]**Announcement Feed**: Admins upload official statements and event captions[cite: 26, 27, 28].
* [cite_start]**Request Forms**: Centralized processing for Clearance [cite: 10][cite_start], Business Permit [cite: 12][cite_start], and Barangay ID[cite: 13].

* **Frontend**: HTML5, CSS3, JavaScript
